# 智能产品业务指标口径说明

## 毛利率 (Gross Margin Rate)

定义: 毛利率 = (营业收入 - 营业成本) / 营业收入 × 100%。

口径说明:
- 营业收入取自订单主表 fact_sales 的 revenue 字段。
- 营业成本取自成本表 fact_cost 的 cost 字段, 按订单维度关联。
- 统计周期以订单日期 order_date 为准, 支持按日/月/季/年聚合。
- 区域维度: 华东 / 华北 / 华南 / 西南 / 东北, 取自客户维表 dim_customer 的 region 字段。
- 若营业成本缺失, 该订单不参与毛利率计算, 并在结果中标注。

使用场景: 管理层经营分析看板、季度经营分析报告。

## 客单价 (Average Order Value)

定义: 客单价 = 营业收入 / 有效订单数。

口径说明:
- 有效订单指状态为已完成的订单, 退款与取消订单不计入。
- 客单价按客户维度聚合时, 称为"客户平均贡献"。

## 复购率 (Repeat Purchase Rate)

定义: 复购率 = 复购客户数 / 活跃客户数 × 100%。

口径说明:
- 复购客户: 统计周期内下单次数大于等于 2 的客户。
- 活跃客户: 统计周期内至少下单 1 次的客户。

## 智能音箱产品线

主打产品包括: 智能音箱、智能手表、无线耳机、智能门锁。
- 智能音箱: 入门级, 客单价约 299 元, 主打家庭场景。
- 智能手表: 中高端, 客单价约 1299 元, 主打健康监测。
- 无线耳机: 走量产品, 客单价约 199 元。
- 智能门锁: 高毛利产品, 客单价约 899 元。

## 数据使用注意事项

- 所有指标必须经由指标语义层计算, 禁止分析师在 Agent 侧自行拼装 SQL, 以保证口径一致。
- 指标结果可追溯到定义版本与底层物理表 (血缘)。
- 涉及客户个人信息时, 需遵守最小化原则并接受脱敏策略 (M3 上线)。
